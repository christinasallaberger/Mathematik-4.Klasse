Zahlenmengen: ℕ = {0, 1, 2, …} · ℤ = {…, −2, −1, 0, 1, 2, …} · ℚ = alle Zahlen, die man als Bruch schreiben kann (auch endliche und periodische Dezimalzahlen) · 𝕀 = irrationale Zahlen: unendlich, nicht periodisch, nicht als Bruch darstellbar · ℝ = ℚ ∪ 𝕀 · ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ

Quadratzahlen bis 15²: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169, 196, 225 – sie enden nie auf 2, 3, 7 oder 8.

Quadrieren: 30² = 900 (Nullen verdoppeln) · 0,3² = 0,09 (Kommastellen verdoppeln) · (a · b)² = a² · b² · (a/b)² = a²/b² · (−4)² = 16, aber −4² = −16

Brüche: (2/3)² = 4/9 · (−3/5)² = 9/25, aber −(3/5)² = −9/25 · √(16/49) = 4/7 · zuerst kürzen: √(8/18) = √(4/9) = 2/3

Wurzeln: √144 = 12 · √0,09 = 0,3 · √1600 = 40 · √(9/16) = 3/4 · √(a · b) = √a · √b · √(a : b) = √a : √b · Achtung: √(a + b) ≠ √a + √b

Wurzel aus einem Produkt: √(4 · 7) = √4 · √7 = 2√7 · √(3 · 25) = 5√3 – aus der Quadratzahl die Wurzel ziehen, die andere Zahl bleibt unter der Wurzel.

Teilweises Wurzelziehen: größte Quadratzahl suchen: √72 = √(36 · 2) = 6√2 · mit Primfaktoren: √180 = √(2 · 2 · 3 · 3 · 5) = 2 · 3 · √5 = 6√5

Wurzeln mit Variablen (Variablen positiv): Hochzahl halbieren: √(x²) = x · √(a⁴) = a² · √(25a²) = 5a · √(12x²) = √(4x² · 3) = 2x√3 · √(x³) = √(x² · x) = x√x

Irrationale Zahlen: √2, √3, √5, π, 0,1010010001… – aber √16 = 4 ist rational, 0,3̅ = 1/3 auch!

Eingabe: Dezimalzahl mit Komma (0,25), Bruch mit / (3/4), Wurzel mit √ aus der Eingabehilfe (2√7).
