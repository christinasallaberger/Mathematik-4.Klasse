Die drei binomischen Formeln:
1. (a + b)² = a² + 2ab + b²
2. (a − b)² = a² − 2ab + b²
3. (a + b)(a − b) = a² − b²

Welche Formel? Drei Glieder → 1. oder 2. Formel: mittleres Glied plus → 1., minus → 2.  Zwei Glieder mit Minus → 3. Formel.

Rückwärts rechnen: 1. a aus a² finden, 2. b aus b² finden, 3. Probe mit dem mittleren Glied 2 · a · b.

x² + 10x + 25 → a = x, b = 5, Probe 2 · x · 5 = 10x ✓ → (x + 5)²

4a² − 12a + 9 → a = 2a, b = 3, Probe 2 · 2a · 3 = 12a ✓, Minus → (2a − 3)²

25x² − 16 → a = 5x, b = 4 → (5x + 4)(5x − 4)

Eingabe: Hochzahl mit ^ oder □², z. B. 9a^2 oder (x+5)^2.
