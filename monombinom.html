Wie heißt du?

Gib zuerst deinen Namen ein. Er steht am Ende in deiner Auswertung. Hast du auf diesem Gerät schon geübt, machst du automatisch dort weiter, wo du aufgehört hast.

Dein Code:

Öffne die Übung auf dem anderen Gerät, gib genau denselben Namen ein und tippe diesen Code ein. Der Code ändert sich, während du weiterarbeitest – schreib ihn dir erst auf, wenn du hier aufhörst.

So geht’s

(x + 2) · (x + 3) = x · x + x · 3 + 2 · x + 2 · 3 = x2 + 3x + 2x + 6 = x2 + 5x + 6

Jedes Glied der ersten Klammer wird mit jedem Glied der zweiten Klammer multipliziert – jeder Pfeil ist ein Produkt.

Das Vorzeichen gehört zum Glied: plus · minus = minus, minus · minus = plus.

Vorzahlen werden multipliziert, Hochzahlen gleicher Variablen addiert: 3x · 2x = 6x2.

Eingabe: Hochzahlen mit ^ oder ², z. B. x^2 oder x². Den Malpunkt kannst du weglassen: 6ab.
